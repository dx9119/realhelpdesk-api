# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются **только для актуальной версии в главной ветке (main)**.

Предыдущие версии не получают патчей безопасности. Если вы используете устаревшую версию, рекомендуется обновиться до актуальной.

## Сообщение об уязвимостях

Исследователям безопасности **запрещено создавать публичные issue** по вопросам безопасности в репозитории.

Любые отчёты об уязвимостях должны направляться **строго на email:** [hellohanov@yandex.by](mailto:hellohanov@yandex.by).

Пожалуйста, включите в ваше сообщение:

- Описание уязвимости и её потенциального воздействия.
- Пошаговые инструкции для воспроизведения (PoC-скрипты, запросы, скриншоты приветствуются).
- Ваши контактные данные для уточнения деталей.
