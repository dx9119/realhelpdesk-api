# Вклад в проект

## Кто может участвовать

Проект разрабатывается **только закрытой, предварительно одобренной группой специалистов**. Участие допускается исключительно по приглашению сопровождающих репозиторий: доступ выдаётся до начала работы, а не по факту присланного изменения.

## Запросы на слияние (Pull/Merge Requests)

Внешние запросы на слияние (Pull Request / Merge Request) **без предварительного согласования не принимаются и будут отклонены**.

Порядок работы для участников закрытой группы:

1. Согласовать задачу с сопровождающими репозиторий.
2. Работать в собственной ветке основного репозитория (не в форке).
3. Оформлять PR/MR только после согласования объёма изменений.

Запросы из форков и внешних веток, присланные без согласования, закрываются без ревью.
